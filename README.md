# Codeforces Solutions

A collection of my solutions to **Codeforces** problems, organized by contest and problem.

The repository is primarily focused on improving problem-solving skills, learning algorithms and data structures, and keeping track of solved problems.

## 🧩 Solutions

Each solution generally contains:

* Problem solution in **C++**
* Standard competitive programming techniques
* Comments where the logic may require additional explanation
* Efficient time and space complexity whenever possible

## 🛠️ Language & Tools

* **C++**
* STL (Standard Template Library)
* GCC / G++

Commonly used concepts include:

* Arrays & Strings
* Sorting & Searching
* Binary Search
* Two Pointers
* Prefix Sums
* Greedy Algorithms
* Recursion & Backtracking
* Dynamic Programming
* Graphs & Trees
* BFS / DFS
* Number Theory
* Bit Manipulation
* Data Structures

## 🚀 Running a Solution

Compile a solution using:

```bash
g++ -std=c++17 -O2 -Wall solution.cpp -o solution
```

Then run:

```bash
./solution
```

On Windows:

```bash
solution.exe
```

## 📌 Notes

* Solutions are written for learning and reference purposes.
* A solution may have multiple approaches; the repository generally contains the approach I used.
* Problem statements and test cases belong to **Codeforces**.
* Always try solving a problem yourself before looking at the solution.
